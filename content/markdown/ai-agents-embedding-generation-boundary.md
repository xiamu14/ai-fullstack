# Embedding 与生成模型有何分工

ID: embedding-generation-boundary

## 题干

一个最小 RAG 链路中，Embedding 模型与生成模型分别做什么？如何避免接错链路？

## 参考答案

1. 建库阶段：将资料切分成可定位的文本块；用 Embedding 将文本表示为可检索的向量并保存关联。

2. 查询阶段：将用户问题转换到与资料可比较的向量空间；取回相关原文证据再交给生成模型组织回答。

3. 接口验证：不能把向量输出当作自然语言生成结果；更换 Embedding 时验证查询与已有索引是否兼容。

纯新手搞Agent开发，最容易栽在两个坑里：一上来就啃源码，被各种抽象概念直接劝退；或者光学理论不动手，代码一行写不出来。下面这条路线我一步步踩过，每一步都落在实处。
一、先把模型调通，消除陌生感
语言选Python，重点搞熟异步编程和Pydantic数据校验，后面写Agent循环和工具调用时，这两个东西高频出现。弄个LLM的API Key，DeepSeek或智谱都行，用几十行代码跑通一次对话，把请求体长什么样、响应结构怎么拆、Token消耗在哪看清楚。别小看这一步，很多人就是卡在第一次调API上，跑通一次心里就有底了。
二、啃下RAG全链路，这是真工程
RAG不是个概念，是实打实的链路：文档切成块、Embedding向量化、存进向量库、用户提问时检索相似块、拼进Prompt喂给LLM。注意，Embedding模型和生成模型是两个不同的API，别搞混。先用Chroma在本地把流程跑通，再上Milvus或Qdrant，亲手感受一下HNSW和IVF这类索引在延迟和召回上的取舍。我当初在这一步被检索慢的问题折腾得够呛，调了索引类型和分块大小才把延迟压下去。
三、拆开Agent的本质，手写一次循环
Agent说白了就是Chatbot加Tools加Loop。LLM推理后判断要不要调工具，要就执行并拿回结果，塞进上下文再推理，直到输出最终答案。先别碰LangChain，用纯Python手写一个ReAct循环，把“思考-行动-观察”每一步打出来，debug时清楚每一步的输入输出。我当初写了不到50行，跑通后那种豁然开朗的感觉，比看十篇教程都管用。
四、工具调用和记忆，拉开差距的细节
Tool是本地函数调用，MCP是远程调用协议，让工具能即插即用。Skill可以渐进式加载，避免一次性塞太多Token。工具不用花哨，bash、文件读写、搜索、编辑器就够用。短期记忆直接靠上下文窗口，长期记忆得靠摘要压缩存向量库，阈值和过期策略就是工程细节。至于Multi-Agent，大部分场景单Agent加两三个工具绰绰有余，别被多智能体带偏了节奏。
五、找一个实战项目，边看边改
拿XingClaw这类开源项目开刀，按顺序啃：总览文档搞懂架构，AI层看LLM接口怎么封装的，核心Agent Loop死磕每一行，内置工具实现研究透，最后看IM层怎么对接飞书。边看边改，把工具换成自己的业务接口，加重试和异常兜底，跑通一个能干活的东西，你就算真正入门了。我那时接了个周报生成Agent，每天定时拉飞书数据调模型写摘要，再推到群里，跑起来那一刻就知道，这玩意儿真能落地。#大模型应用[话题]# #agent[话题]# #人工智能[话题]# #AI应用开发[话题]# #大模型[话题]#

现在很多人的 AI 学习路线是：Prompt → RAG → Agent，先拼出一个 Demo 再说。
我反而建议先刹车。真做项目时，更容易把人卡住的是：数据不会处理，模型为什么出错说不清，本地能跑，却上不了线。
AI Engineer 不是“会用 ChatGPT 的程序员”。你要能把数据、模型、应用和部署串成一条真正能运行的链路。

所以我更认可这个顺序：
🐍 先用 Python 拿到“干活能力”
变量、循环、函数、OOP、异常和文件处理是底座；NumPy 处理数值与数组，Pandas 清理脏数据，Matplotlib 把数据画出来。学完就做小项目，计算器、问答游戏都可以。重点不是项目有多酷，而是你能不能自己写、自己查错。

🧠 再补数学、ML 和 DL
数学不用学成数学系，但要能理解模型怎么从数据里找规律、做预测、再根据错误调整。接着进入监督/无监督学习、分类、回归、特征工程，然后再学神经网络、前向/反向传播和损失函数。
这部分看起来没 Agent 性感，却决定了模型出 badcase 时，你是只会换个 Prompt，还是真能找到问题。

🤖 然后才是 LLM 和 Agent
先搞懂 NLP、Vector、Embedding 和向量数据库，再学 RAG：模型不知道你公司的私有数据，怎么让它基于这些数据给出回答？
再往后才是 Agent。普通 GenAI 可以帮你查航班；Agent 要做的是把查航班、做行程、订酒店连成一段 Workflow。一个 Agent 真正跑起来，至少要组合 LLM、Memory 和 Tools，这时再看 LangChain、LangGraph 才有上下文。

🚀 本地跑通还不算完 你得让别人真的用上它。Git/GitHub、Docker、云服务、MLflow、Apache Airflow，这些才会把一个本地模型变成可管理、可部署的系统。

整条路线至少可以按3个月、每天 2–4 小时的投入做预期。别只收藏课程，每学一层就做一个可展示的东西，放到 GitHub 或 LinkedIn 上。
