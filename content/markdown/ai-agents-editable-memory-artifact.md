# 长期记忆为何需要用户可见

ID: editable-memory-artifact
Library: ai-agents
Version: 2026-10-24.1

模块：上下文记忆 · 难度：L2

## 题干

记忆保存成可读文件相较于完全隐藏的内部状态有什么价值，还需要哪些治理措施？

## 参考答案

1. 可见可改：用户能够查看系统具体记住了什么；允许纠正或删除错误及不再适用的记忆。

2. 变更追踪：保留记忆的来源与修改历史；提供可恢复的版本以便回滚错误变更。

3. 读取治理：可读载体仍需权限与隐私边界；检索或注入时检查时效和冲突而非盲信文件内容。
