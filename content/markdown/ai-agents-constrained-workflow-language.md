# 受限工作流语言有何价值

ID: constrained-workflow-language
Library: ai-agents
Version: 2026-10-24.1

模块：决策编排 · 难度：L3

## 题干

为什么有的 Agent 系统用不支持循环、递归或任意变更的 DSL 描述工作流？其收益与代价是什么？

## 参考答案

1. 流程显式：将步骤与依赖写成可检查的结构化工作流；使人和执行器能够核对流程含义。

2. 能力约束：限制循环递归或任意状态变更可减少难分析的行为；由解释器统一落实工具调用与验证边界。

3. 适用取舍：受限表达力会降低部分灵活性；用业务任务验证可检查性收益是否值得这种限制。
