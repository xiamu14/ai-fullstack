# Skill 路由应看哪些信号

ID: skill-routing-signals
Library: ai-agents
Version: 2026-10-24.1

模块：工具执行 · 难度：L4

## 题干

大量 Skill 名称相近时，怎样验证实现正文是否比名称和描述更有助于路由，并处理等价技能？

## 参考答案

1. 信号消融：分别比较名称描述和实现正文等候选特征；在相同任务与候选集下检验各信号的实际贡献。

2. 标签边界：识别能够正确完成同一任务的等价技能；不能把所有非首选技能无条件标为错误负样本。

3. 检索排序：分别评估候选召回与重排后的首选准确率；结合读取正文的开销与错误案例调整路由方案。
