# 跨昼夜发布为何不能只靠 Skill

ID: durable-release-workflow
Library: ai-agents
Version: 2026-10-24.1

模块：系统设计 · 难度：L4

## 题干

发布任务持续十几个小时并要等次日流量验证，为什么完整操作手册仍不足以保证 Agent 可靠执行？

## 参考答案

1. 知识与状态：Skill 描述操作知识但不自动记录本次执行进度；任务状态需持久化以跨进程和会话继续。

2. 流程约束：将关键步骤及放行条件编码成可核对的模板或流程；引擎依据真实环境验证后再推进发布阶段。

3. 长程变化：等待期间应保存检查点并重新核对环境变化；故障后按已验证状态恢复且不盲目重复发布副作用。
