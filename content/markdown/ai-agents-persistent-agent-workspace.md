# 常驻 Agent 工作台如何受控

## 题干

一个常驻 Agent 可从聊天、语音等多个入口接任务，还能保留浏览器和文件，应该怎样管理状态与人工接管？

## 参考答案

1. 空间隔离：按 Agent 身份隔离工作空间与工具权限；明确文件和登录等持久状态的保存及访问范围。

2. 多入口一致：不同入口关联同一任务状态避免重复执行；共享资料更新需要冲突检测或版本控制。

3. 人工控制：对要求批准的保存或发布动作在确认后执行；人工接管时协调暂停与恢复使双方不会并发覆盖状态。

CopilotKit 开源了 OpenDots——一个自建版的 Dots：自己家搭一套常驻 AI 员工，每个都有自己的电脑，能聊天、打电话、在 Slack 里接活。

跟前两天那个「连夜手搓版」不一样，这是相对完整的一套可自托管模板，克隆回去就能二改。

💻 每个 Dot 有自己的电脑：能开浏览器、存文件、跑命令，而且浏览器登录状态和文件重启后还在。
✅ 先批后存：聊天里弹出「批准保存 / 拒绝」卡片，你同意了才真的进 Space。
🙋 人工接管：随时能自己接过来动手。
🔀 多入口：同一个 AI 同事，网页聊天、语音通话、Slack 里都能找到它；长任务挂后台跑，通话和聊天继续。

📁 Space 相当于你和 AI 同事共用的资料夹／工作台，用来存页面、笔记、草稿，支持搜索、嵌套页面、自动保存和版本冲突保护。每个 Dot 都有自己的名字、角色说明、可用工具和权限。

⚠️ 目前还是 Alpha 阶段，偏单人使用，不支持完整的多人协作、共享编辑和文件上传。
