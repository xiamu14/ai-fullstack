# 模型路由如何平衡质量与成本

ID: model-task-routing
Library: ai-agents
Version: 2026-10-24.1

模块：模型交互 · 难度：L2

## 题干

准备把简单任务交给小模型、复杂任务交给强模型，你会如何验证路由策略？

## 参考答案

1. 任务划分：按任务需求与难度建立可检查的路由规则；用实际业务样本而非仅靠主观判断区分任务。

2. 模型对照：比较各候选模型在对应任务上的质量；同时记录实际费用和响应时间。

3. 路由评估：检查误分任务带来的质量损失；将整体完成率与成本一起评估并监测变化。
