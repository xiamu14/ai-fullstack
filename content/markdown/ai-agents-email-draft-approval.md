# 邮件草稿如何经批准后发送

ID: email-draft-approval
Library: ai-agents
Version: 2026-10-24.1

模块：工具执行 · 难度：L3

## 题干

Agent 读邮件并拟定回复，由用户批准后发送，服务端怎样保证发出的是用户看到并同意的那一版？

## 参考答案

1. 草稿绑定：把收件人正文及附件等发送内容保存为可审查草稿；批准记录绑定具体草稿版本而非泛泛同意未来所有邮件。

2. 发送前检查：检查批准者身份权限及批准仍然有效；草稿修改后需要重新核对授权不能沿用旧版本的同意。

3. 发送一致性：用发送标识去重避免重复提交导致多封邮件；记录真实发送结果与失败状态而非以模型声称已发送为准。
