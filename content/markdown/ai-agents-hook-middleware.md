# Hook 与 Middleware 如何区分

ID: hook-middleware
Library: ai-agents
Version: 2026-10-24.1

模块：工具执行 · 难度：L2

## 题干

请比较 Hook 与 Middleware 在 Agent 系统中的介入方式和典型用途。

## 参考答案

1. Hook 介入：Hook 在命名的生命周期事件或边界触发；适合在开始结束等事件执行检查或记录。

2. Middleware 介入：Middleware 包装一次调用的前后过程；可检查修改请求或处理响应和异常。

3. 边界选择：根据要控制的生命周期或调用范围选择机制；权限及失败处理仍需明确执行策略而非仅依赖命名。

Hook（钩子）：在框架预留的关键节点插入自定义逻辑，比如请求前、渲染后，你挂上去，框架到点就调你。
Middleware（中间件）：请求处理链条中的一环，像流水线，一个传一个，可拦截、加工、放行请求。
SO：Hook 是「到点触发」的挂点，Middleware 是「层层过手」的管道
