# 执行轨迹如何便于核查

ID: trace-inspection
Library: ai-agents
Version: 2026-10-24.1

模块：工程质量 · 难度：L2

## 题干

Agent 的原始轨迹很长，如何降低人工理解成本，又能让关键结论有据可查？

## 参考答案

1. 分层浏览：先展示任务阶段或决策结构的概览；支持展开到具体动作与结果避免一次展示全部细节。

2. 证据关联：从关键结论或节点定位对应原始记录；保留动作顺序或依赖关系便于理解决策过程。

3. 原文保留：完整保存原始轨迹而非只留下 AI 总结；允许审查者核对总结与原始证据的一致性。

认知债务是 AI 时代比技术债务更危险的隐性风险。

Karpathy说，接下来我们需要花越来越多时间去理解模型的输出。

但当我们想要理解Agent的行为时，动辄千百万字并包含大量思考记录和工具调用记录的原始轨迹，产生了极大的认知负担。

结果就是，在现实压力下，人们越来越难在有限的时间内充分理解Agent的行为以及他们最终的产物。

Agent们到底尝试了哪些方向？最终的版本究竟是它们基于怎样的思考和证据得到的？如果不去理解这些，必然会成为隐形的“认知债务”，使得工作对象的长期维护变得步履维艰。

为此，我们发布了基于人类认知习惯的Agent轨迹理解工具：TraceVista。

人在理解复杂事物时，总是先把握全貌，再深入细节，并在关键处求证。
TraceVista 循着这一习惯重新组织 Agent 的轨迹：

TraceVista首先将复杂的Agent原始轨迹变成一棵方便理解的决策树。

而当某一步引起你的疑问时，你可以就地展开它：从工作阶段到具体动作，再到原始记录，层层深入的同时也可以快速脱离，避免迷失在上下文中。

但无论总结写得多么好，TraceVista 都完整保留了 Agent 的原始记录，让每一个判断都有据可查。

我们相信对Agent行为的理解，终究不该建立在对另一段 AI 总结的信任之上。
