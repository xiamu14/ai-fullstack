# 如何让关键词搜索更可靠

ID: searchable-knowledge-layout
Library: ai-agents
Version: 2026-10-24.1

## 题干

知识库准备主要使用 grep 等关键词搜索，应该怎样组织资料并识别这种方案的局限？

## 参考答案

1. 可搜结构：为文档建立稳定标题标识与字段结构；维护术语别名以减少用词差异造成的漏检。

2. 证据定位：提供索引或目录帮助定位相关文件；搜索结果保留可引用的原文位置与必要上下文。

3. 效果边界：用真实问题检查精确匹配和语义改写的召回差异；根据漏检与维护成本判断是否需要补充其他检索方式。
