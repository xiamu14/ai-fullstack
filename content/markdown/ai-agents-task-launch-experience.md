最近在研究一个很有意思的问题：

我看了 Manus、ChatGPT、Claude、Genspark 之后，越来越确定一件事：

Agent 首页不应该是“功能导航页”，而应该是“任务启动器”。

传统 SaaS 首页在回答：

“我有哪些功能？”

但 Agent 首页真正应该回答的是：

“你现在可以让我替你完成什么工作？”

这也是很多 Agent 产品冷启动做不好的根源。

用户打开首页，看到一个空白输入框：

“有什么可以帮你？”

然后用户脑子里只有一句话：

“所以我到底该让你干嘛？”

我把 Agent 冷启动拆成了两个问题：

1. 用户不知道 Agent 能做什么
→ 用任务示例、模板、推荐动作解决。

2. Agent 不知道用户是谁
→ 用 Memory、Projects、历史任务、知识库、Connectors 解决。

所以我现在更喜欢这样的 Agent 首页：

* 继续昨天的工作
* 推荐今天最值得推进的任务
* 根据上下文主动给建议
* 最后才是那个万能输入框

一句话：

不要让用户先学会怎么使用 Agent。
先让 Agent 帮用户把第一件事做成。

我把 Manus / ChatGPT / Claude / Genspark 的首页案例，以及一套可以直接落地的 Agent 首页设计框架整理成图了。
