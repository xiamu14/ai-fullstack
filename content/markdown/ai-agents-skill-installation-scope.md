# 安装 Skill 如何控制范围

ID: skill-installation-scope
Library: ai-agents
Version: 2026-10-24.1

模块：工具执行 · 难度：L2

## 题干

用户只授权安装仓库中的一个 Skill 子目录，怎样确认安装成功又没有扩大操作范围？

## 参考答案

1. 范围核对：确认目标仓库子目录及本地安装位置；不把安装授权扩展为运行示例或执行任意仓库脚本。

2. 内容检查：核对 SKILL.md 与所需脚本参考资料是否完整；检查路径与依赖避免误装无关目录。

3. 发现验证：确认目标客户端能发现该 Skill；通过可审查的文件记录报告安装结果与范围。
