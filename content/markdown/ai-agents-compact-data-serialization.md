## 题干

想把重复字段较多的 JSON 改成更紧凑的表格式输入，怎样验证节省 Token 的同时没有改变语义？

## 参考答案

1. 结构压缩：对同构数据可抽出共享表头以减少重复字段；保留记录数与字段对应关系以避免歧义。

2. 往返校验：用编码解码往返测试核对值类型和结构；覆盖空值转义嵌套及精度等边界数据。

3. 任务检验：使用目标模型实测 Token 数与解析效果；比较下游任务正确率而非假设所有数据都能受益。
