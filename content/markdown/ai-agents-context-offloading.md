# 上下文卸载如何可回查

ID: context-offloading
Library: ai-agents
Version: 2026-10-24.1

模块：上下文记忆 · 难度：L3

## 题干

长任务把中间结果移到外部存储后，怎样减少上下文占用而不丢掉后续所需信息？

## 参考答案

1. 外置原文：将大体积中间结果保存在持久存储；上下文仅保留概要与稳定定位标识。

2. 按需展开：维护任务节点或索引与原文的关联；遇到细节问题时能按定位重新读取原文。

3. 完整性验证：检查引用有效以及关键细节能够找回；对比卸载前后的任务质量和 Token 消耗。

长任务跑AI Agent的都知道，上下文一满就开始失忆，Token费用也跟着起飞。腾讯这个方案用「上下文卸载+Mermaid任务画布」，把中间结果存到外部，上下文只留摘要和索引。信息按四层结构存储，每一层都能百分百找回，不是黑盒压缩。
最巧妙的是那张Mermaid画布，把任务执行过程变成一张可导航的地图，Agent不用记住所有内容，只需要知道信息在哪、怎么展开。
Token降61%的同时，任务成功率反而上升了，因为上下文噪声少了，注意力更集中。零外部依赖，本地SQLite就能跑。
