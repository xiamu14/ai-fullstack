## 题干

请说明一个能调用工具的最小 Agent 循环，以及它如何停止。

## 参考答案

1. 循环步骤：模型根据当前任务选择工具及参数；执行工具并把真实结果回填后再次调用模型。

2. 终止条件：完成目标时停止循环；为轮次或时间设置上限以避免无限循环。

3. 异常处理：将工具失败作为可观察的执行结果；根据失败原因决定修正参数或结束任务。
