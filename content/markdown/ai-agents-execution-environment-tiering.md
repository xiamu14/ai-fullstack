# 轻任务与重任务如何选择环境

ID: execution-environment-tiering
Library: ai-agents
Version: 2026-10-24.1

模块：系统设计 · 难度：L3

## 题干

同一个 Agent 既做轻量脚本又要跑大型构建，如何按任务选择执行环境并管理共享文件？

## 参考答案

1. 需求识别：根据任务依赖资源与隔离需求区分轻重工作；不能只按启动速度忽略运行能力和权限边界。

2. 按需环境：轻任务在满足约束的轻量环境执行；需要更重依赖或资源时再使用合适的容器环境。

3. 文件一致：明确环境切换时文件版本与同步方向；验证权限隔离以及切换前后产物的一致性。
