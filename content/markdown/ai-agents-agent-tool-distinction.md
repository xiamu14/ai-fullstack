# Agent 与工具有什么区别

ID: agent-tool-distinction
Library: ai-agents
Version: 2026-10-24.1

模块：工具执行 · 难度：L1

## 题干

请用一个查询并交付结果的任务，解释普通工具调用与 Agent 的区别。

## 参考答案

1. 工具契约：工具执行明确输入输出约定的一次操作；工具成功不等于整个用户目标已经完成。

2. 自主循环：Agent 围绕目标选择和组织多个动作；根据工具反馈决定继续修正或结束。

3. 执行边界：Agent 使用工具时仍受权限与参数校验约束；对用户交付需要检查实际结果而非只输出完成声明。

你有没有想过，为什么现在的AI只会聊天，不能帮你干活？

比如你说"帮我订一张明天去上海的机票"
ChatGPT会告诉你"我可以帮你查询航班信息"
但最后下单、支付、选座，还是得你自己动手

这就是今天要讲的：AI Agent

✨ 一句话定义

AI Agent = 能帮你把事情做完的AI
不是只会陪你聊天的那种

🍔 用外卖下单理解

普通AI：你问"附近有什么好吃的"
→ 它推荐了几家店
→ 你自己去搜、去下单、去等外卖

AI Agent：你说"我想吃川菜，预算30块"
→ 它自己去搜店、看评价、比价、下单
→ 全程不用你动手
→ 最后告诉你"已下单，预计25分钟到"

核心区别：
普通AI只给你信息
AI Agent能替你行动

💼 再举个工作场景

普通AI：你说"帮我写周报"
→ 它给你写了一段文字
→ 你自己复制粘贴到Word里

AI Agent：你说"帮我写周报"
→ 它自动打开文档、整理数据、生成报告、发邮件
→ 你最后只收到"周报已发送"

🤖 Agent的组成

Agent = 大脑（大模型）+ 手（调用工具）+ 脚（执行任务）

大脑：理解你的需求
手：打开浏览器、日历、邮件等工具
脚：按步骤一步步执行

💡 总结

普通AI：你提问 → 它回答 ✅ 完
Agent：你提需求 → 它拆解 → 它搜索 → 它整理 → 它交付 ✅ 完
