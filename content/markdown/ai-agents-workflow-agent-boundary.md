# 固定工作流和 Agent 如何选择

ID: workflow-agent-boundary
Library: ai-agents
Version: 2026-10-24.1

模块：决策编排 · 难度：L2

## 题干

哪些业务适合固定工作流，哪些需要动态 Agent？如何组合两者？

## 参考答案

1. 固定路径：步骤与依赖明确且要求稳定时适合工作流；用显式分支和状态规则处理已知变化。

2. 动态路径：需要根据新信息选择工具或调整步骤时适合 Agent；动态决策仍应受目标权限与预算约束。

3. 混合方案：可将确定阶段固化而在开放节点使用模型决策；用实际任务比较质量可控性与运行成本。
