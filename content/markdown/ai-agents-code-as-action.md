# 代码为何适合承载复杂动作

ID: code-as-action
Library: ai-agents
Version: 2026-10-24.1

模块：工具执行 · 难度：L2

## 题干

Agent 使用代码表达多步操作，相比只能逐个调用固定工具有什么价值和风险？

## 参考答案

1. 表达能力：代码可以表示循环条件及函数组合；变量与数据结构便于保存并复用中间结果。

2. 反馈验证：执行代码后根据实际输出或错误调整；对任务结果做断言而非把代码可运行当作语义正确。

3. 运行约束：在受控环境中限制代码可访问的资源；校验或审批高风险副作用而非赋予无限宿主权限。
