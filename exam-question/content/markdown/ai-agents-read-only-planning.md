# 首次执行前如何设边界

## 题干

用户让 Agent 整理一个陌生目录，如何先了解现场并形成可以确认的方案？

## 参考答案

1. 观察范围：先以只读方式检查文件类型和目录结构；分析阶段不移动修改或删除文件。

2. 可审查方案：列出建议的整理动作及受影响文件；标出高风险项目和需要确认的事项。

3. 执行依据：让用户确认具体方案或依据已有授权执行；实际操作前再次核对范围与当前文件状态。

这是我准备开的一个系列：AI Agent 教程。

不讲玄学，不讲参数榜单。每一篇只解决一个上手问题。

第 1 篇先讲一个最重要的习惯：

第一次使用 AI Agent，先别让它动手。

因为 AI Agent 和普通聊天机器人不一样。

它可能真的进入你的目录、读取文件、运行命令、修改项目。

所以第一步不是“让它帮你干活”，而是：

观察 → Plan → 确认 → 执行

这篇用“整理文件夹”做练习。

不是因为文件夹本身多重要，而是它足够简单，适合练习给 AI 设边界。

可以直接复制这段给 Agent：

请你先不要修改、移动、删除任何文件。

请扫描当前目录，并完成：
1. 判断主要文件类型
2. 给出整理方案
3. 标出高风险文件

输出：
- 观察到了什么
- 建议怎么整理
- 哪些需要人工确认
- 下一步怎么做

注意：只允许分析和建议。

核心只有一句：

先让它看懂现场，再决定要不要执行。

这个习惯后面做代码、写文章、处理表格、搭 MCP 都会用到。
