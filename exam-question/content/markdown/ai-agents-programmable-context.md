# 可编程上下文如何受控

ID: programmable-context
Library: ai-agents
Version: 2026-10-24.1

模块：上下文记忆 · 难度：L3

## 题干

Agent 可以把上下文作为变量读写，并保存跨会话规则。如何防止它越改越偏？

## 参考答案

1. 状态分离：区分当前推理的临时上下文与持久规则；明确哪些状态可以修改以及各自作用范围。

2. 受控变更：对上下文读写保留可检查的操作与来源；持久规则变更需要验证适用性而非任意覆盖。

3. 恢复验证：保留版本或检查点以恢复错误变更；用跨会话任务验证有用信息持续可用且无无关污染。
