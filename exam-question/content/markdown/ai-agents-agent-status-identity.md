## 题干

多 Agent 界面中，怎样让用户既分清身份，又看懂正在执行、等待或已完成等状态？

## 参考答案

1. 身份稳定：为不同 Agent 提供稳定的名称或视觉标识；状态变化时仍能识别它是同一个 Agent。

2. 状态表达：依据实际运行状态区分执行等待完成与失败；使用文字图标等线索而非只靠颜色传递含义。

3. 一致反馈：界面状态应跟随可验证的任务事件更新；提供必要的任务详情而不是用装饰动画代替进度。

Agent 头像应该是状态栏，而不是证件照
最近看到 Oreo UI，一个专为 AI Agent 设计的 Figma 组件库，特别喜欢它的 avatar ui library。

以前给 Agent 设计头像时，我总会下意识地沿用人类世界里的方式：真人照片、卡通人物，或者某种拟人化形象，背后的思考是用看待人类的视角看待 Agent。但后来我觉得，人类的头像反而让其失去了一些灵性和智能。

但后来我慢慢觉得，一张人脸反而限制了 Agent，人类或卡通头像能让 Agent 看起来更亲切，却未必更容易识别。尤其是在多 Agent 场景里，如果每个 Agent 都顶着一张相似的人脸，用户第一眼仍然分不清它们，最后还是得逐个查看名字，最后反而增加了产品使用的心智负担。

当然，没有人会用自己的证件照来当头像吧:)，而我最常用的 Agent 是一个哈基米头像。

Oreo UI 给了我一个很有启发的方向：Agent 的头像不一定要模拟某个人。它可以用颜色、渐变、形态和动态，表达自己的身份与状态。

不同的视觉特征，可以帮助用户快速区分不同 Agent；同一个 Agent 也可以通过颜色和形态的变化，表达它正在思考、执行任务还是等待回应。

即使一个系统里只有一个 Agent，这些变化也能让用户感受到它当下的状态，不同的颜色可以呈现不同的情绪，这是一种很有温度的交互。

我开始重新思考问题： “我怎样一眼认出它，又怎样知道它此刻正在做什么？”

Agent 不需要一张人类的脸，它需要一种属于自己的视觉语言。

[Agent 跑任务，进度不能只有一句“执行中”](https://www.xiaohongshu.com/explore/6ab4be7e0000000014039645)，ZZ.X，2026-10-04T02:18:01.000Z，仅正文。

这个 AI Todo List 把任务执行压缩成了一张很清楚的进度卡：

- 顶层展示任务名称和已完成步骤数
- 子任务逐条列出，让执行计划可以被检查
- 当前步骤持续显示进度，而不是只有 loading
- 已完成、执行中和未开始拥有明确状态差异
- 收起后仍保留整体进度，避免打断主工作区

它的价值不是“像待办清单”，而是把 Agent 的内部计划变成用户可以理解和监督的外部状态。

适合代码重构、资料研究、批量生成和数据处理等多步骤任务。任务越长，越不能只告诉用户“正在处理”，而要让他知道系统正在按什么路径推进。
