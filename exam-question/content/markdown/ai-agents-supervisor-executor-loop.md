# 实时监督如何纠偏而不互相污染

ID: supervisor-executor-loop
Library: ai-agents
Version: 2026-10-24.1

模块：决策编排 · 难度：L3

## 题干

让监督者在 Agent 执行中发现偏航并纠正，应该怎样组织上下文、干预和经验沉淀？

## 参考答案

1. 角色隔离：执行者聚焦当前任务而监督者检查目标与进度；双方保留足够独立的上下文以减少共同陷入错误。

2. 实时干预：依据停滞偏航或违反约束的证据触发纠正；在受控边界调整或暂停执行而非无限反复指挥。

3. 经验验证：将已核实的失败教训转成可复用记忆或技能；验证后续任务收益并区分框架改进与模型权重更新。

让 Agent 干长活——装环境、修跨文件 bug、搭管线——最大的痛点是中途走偏后会一直错下去；等跑完再复盘，这一轮已经浪费了。

PILOT 把自我改进搬进执行过程，核心是两个设计：
[一R] 实时纠偏：「监督者」全程盯着「执行者」，发现走偏、停滞，当场纠正或叫停重来。上下文分离开，会让「监督者」更清醒，也会让「执行者」更专注和不钻牛角尖。
[二R] 实时进化：执行中踩过的坑，即时沉淀成可复用的技能和记忆，下个任务直接带着用。

结果（模型全程冻结，对比的是框架本身的能力）：
[星R] 6 个配置 5 个第一；Terminal-Bench 2.0 最高领先 9.8 个百分点
[学生党R] 连续自我改进：提升 14.6 / 12.4 分，平均输出 token 省近一半
[飞机R] 每百万 token 的成功评测数，翻倍以上。涨分集中在难任务——难活最吃「上次踩坑的经验」，这恰好是技能库沉淀的东西。
