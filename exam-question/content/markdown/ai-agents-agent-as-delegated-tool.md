# 把另一个 Agent 当工具如何约束

ID: agent-as-delegated-tool
Library: ai-agents
Version: 2026-10-24.1

模块：决策编排 · 难度：L3

## 题干

主 Agent 把 Coding Agent 当作工具调用时，如何避免委派关系变成无限权限和失控递归？

## 参考答案

1. 委派契约：说明子 Agent 的任务范围输入及期望交付；限制子调用可用的工具与操作权限。

2. 资源边界：为嵌套委派设置深度调用量或时间预算；避免主从互相反复委派而没有终止条件。

3. 结果核验：把子 Agent 的报告视为待核验交付而非自动正确；检查实际产物及副作用后再向用户确认完成。
