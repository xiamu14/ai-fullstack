## 题干

准备让模型按细则评分。如何判断问题出在评分细则、人工标签还是模型裁判？

## 参考答案

1. 人工一致性：让多名标注者独立按同一细则评分；分析分歧以判断细则是否清楚可操作。

2. 模型对齐：将模型结果与经过复核的人工标签比较；分别检查分项误差及关键错误的漏报误报。

3. 独立验证：用开发集调整细则或阈值；保留独立验证集并记录不确定和失败样本。

1. Agent 评测的核心是回答好不好，且必须同时看结果与行为过程。
两个 Agent 同样做对任务，工程价值可能差别巨大；评测需覆盖结果、过程、效率、风险，避免把偶然命中误判为真实能力。
2. 评测体系的核心不是堆指标，而是在业务价值与模型能力之间搭桥。
模型能力指标与业务结果指标之间存在天然鸿沟，需要面向任务系统的中间能力指标串联，才能回答业务指标为何变差或模型能力提升为何没带来收益。
3. 主观评测应通过人人一致、人机一致来对齐标准。
关键做法是让权威角色拉齐各方标准、将模糊指标拆解并二元化为 Rubric评分精细维度，用一致率阈值反查指标制定的是否合理；
4. Agent 评测是实践中优化的，起步别追求完美。
采集、清洗、评测、质检、分析五环节构成迭代循环；先定义少量关键指标，从线上真实环境取 Bad Case 暴露短板、Good Case 定义什么叫"好"，逐步沉淀评测资产。
5. 长程 Agent 时代，评测从答案评测走向行为评测，从人评主导走向机评主导。
评测对象从单一模型变为模型加系统、工具、流程的复杂系统，关注任务完成度与轨迹质量；人工聚焦标准设计与 Rubric 对齐，AI 负责将人的标准放大规模化。
