# 结构化输出如何校验

ID: structured-validation
Library: ai-agents
Version: 2026-10-24.1

模块：模型交互 · 难度：L2

## 题干

模型已经输出 JSON，为什么服务端仍然需要校验？应分哪些层次？

## 参考答案

1. 语法校验：先解析 JSON 以确认语法有效；语法有效不等于字段符合约定。

2. 结构校验：用 schema 检查字段类型和必填项；对枚举或数值范围进行约束。

3. 业务校验：检查跨字段关系和业务权限等领域规则；校验失败时阻止无效结果进入业务执行。
