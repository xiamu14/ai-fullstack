# 更换模型后工具为何失效

ID: model-tool-compatibility
Library: ai-agents
Version: 2026-10-24.1

模块：工具执行 · 难度：L2

## 题干

Agent 更换模型供应商后，原本可用的搜索功能消失了，应如何排查集成边界？

## 参考答案

1. 能力归属：区分供应商内置能力与应用自己提供的工具；确认新模型接口支持需要的工具调用契约。

2. 接入核对：检查工具注册权限及输入输出结构；通过独立工具测试确认服务本身可用。

3. 链路验证：用明确需要搜索的任务验证选择执行与回填；记录不支持能力并明确配置而非宣称换端点即可完全兼容。
