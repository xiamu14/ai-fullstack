# 分类决策何时不必生成长文

ID: non-generative-decisions
Library: ai-agents
Version: 2026-10-24.1

模块：模型交互 · 难度：L2

## 题干

工作流只需要决定下一步路由或一个等级分数。为什么可考虑有类型的决策接口？还应验证什么？

## 参考答案

1. 输出匹配：将固定路由表示为枚举或分类结果；将评分表示为受约束的等级而非自由长文。

2. 工程收益：结构化决策便于程序校验与分支处理；不需要解释时可避免无用的长文本生成。

3. 可靠性边界：概率或置信度不能直接等同于业务正确率；用实际标注样本验证准确率并校准决策阈值。

【开源】LLM 不是什么事情都需要调用。Strands Decider 专门把 Agent 里的“判断题”拿出来，用一个 1.9B 参数的小模型解决。

它可以判断是否调用某个工具、选择哪个模型、把请求分给哪个团队，也可以给内容打分。和普通 LLM 不同，它不生成文本，而是一次前向计算直接返回决策和置信度。

官方测试中，RTX 3090 上单个问题中位延迟约 115ms；置信度达到 0.9 以上时，在短分类任务上约 95% 的判断是正确的。
