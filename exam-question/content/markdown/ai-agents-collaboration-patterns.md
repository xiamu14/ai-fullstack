# 多 Agent 协作模式如何选择

ID: collaboration-patterns
Library: ai-agents

## 题干

请对比主管分派、接力、讨论与投票四种协作模式，并说明选择依据。

## 参考答案

1. 组织方式：主管模式集中拆分与分派而接力模式按阶段交付；讨论模式通过交互形成结论而投票模式聚合独立候选。

2. 任务匹配：根据依赖关系和专业分工选择组织方式；需要投票时应关注候选独立性与评判规则。

3. 协调成本：评估通信延迟与额外 Token 成本；明确冲突裁决和结束条件以避免无休止协商。
