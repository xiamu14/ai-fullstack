# 只有输入输出能评测什么

ID: blackbox-observability
Library: ai-agents
Version: 2026-10-24.1

模块：工程质量 · 难度：L2

## 题干

你只能访问 Agent 的输入和最终输出，没有内部 Trace。哪些结论可以验证，哪些需要额外观测？

## 参考答案

1. 结果范围：可以检查最终输出格式和任务结果是否符合要求；结论范围应限定为可获取的输出或外部业务状态。

2. 过程盲区：不能仅凭正确答案确定内部工具参数和路径都正确；成本浪费或中间未授权行为需要相应过程证据。

3. 观测补全：若需诊断过程应接入调用与状态等结构化事件；使用关联标识把中间事件和最终任务结果连接起来。

大厂往往有能力基于底层框架自建全链路基建，而中小团队更倾向于使用成熟的开源或SaaS方案，通过SDK集成来低成本实现Trace追踪和效果评估。

以下梳理Langfuse、LangSmith、Coze Loop、Phoenix (Arize) 和 Ragas 五大主流方案。
当前 Agent 评测平台主要分为
1、开源可观测性平台，适合中小团队自托管
2、商业一体化平台，功能最强但付费
3、自建AI基建平台+评测平台

以下从核心定位、关键能力、部署成本及适用场景四个维度进行梳理。

补充，使用 Codex 等外部 Agent 进行评测本质上属于黑盒测试，仅能基于输入和输出来验证最终结果的准确性、格式合规性及安全性，而无法触及执行过程。由于缺乏对内部 Trace（追踪数据）的访问权限，外部 Agent 无法观测推理路径、工具调用逻辑及中间状态，因此难以发现“答案正确但逻辑错误”或“资源浪费”等深层问题，必须结合 Langfuse 等可观测性平台才能实现从结果到过程的完整白盒评测。
