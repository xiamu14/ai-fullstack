# Agent 执行环境如何隔离

ID: runtime-sandbox
Library: ai-agents
Version: 2026-10-24.1

模块：系统设计 · 难度：L3

## 题干

Agent 需要执行不完全可信的代码。选择轻量隔离或容器时，应如何判断安全边界？

## 参考答案

1. 威胁模型：先明确代码信任程度与需要保护的资源；列出文件系统网络及凭证等访问风险。

2. 隔离措施：选择与威胁相匹配的进程或容器等隔离边界；限制文件网络以及 CPU 内存等资源权限。

3. 开销权衡：比较隔离强度与启动和运行开销；用逃逸或越权测试验证边界而非只比较速度。
