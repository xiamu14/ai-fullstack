# 存储检索与反思如何区分

ID: memory-retain-recall-reflect
Library: ai-agents
Version: 2026-10-24.1

模块：上下文记忆 · 难度：L3

## 题干

记忆系统提供 retain、recall 和 reflect，三者分别承担什么职责？怎样避免反思结果被当成原始事实？

## 参考答案

1. 写入事实：retain 保存可追溯的事实及其来源；把原始证据与后续概括区分保存。

2. 组合召回：recall 可结合语义关键词关系与时间检索；融合排序后按任务需要和预算选择结果。

3. 反思边界：reflect 基于记忆形成推断或概括而非自动产生新事实；推断需标明依据与不确定性并验证额外计算成本是否值得。

AI Agent最大的痛点是什么？每次对话都从零开始，昨天聊的全忘了。今天拆解的Hindsight就是来解决这个问题的。
Hindsight不是普通的记忆系统，它让AI Agent真正学会积累经验。和RAG只做检索不同，它会自动把零散事实整合成观察，再从观察中提炼出心智模型。
三个核心操作：retain存入记忆，recall检索记忆，reflect深度推理。最厉害的是recall会同时跑语义、关键词、图谱和时间四路检索，再融合排序。
两行代码就能接入，用LLM Wrapper包一下现有客户端，记忆自动存取。支持60多个集成，Claude Code、Cursor、LangGraph都能直接用。
部署也简单，Docker一条命令搞定，还支持25种以上LLM。
注意：它的检索精度高但token消耗也比Mem0大不少，简单场景可能用不上这么重的方案。
