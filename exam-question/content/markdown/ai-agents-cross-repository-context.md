# 跨仓库修改如何建立全局上下文

ID: cross-repository-context
Library: ai-agents
Version: 2026-10-24.1

模块：上下文记忆 · 难度：L3

## 题干

一个功能横跨多个仓库，Agent 总是只改当前仓库。如何构建可持续的系统上下文？

## 参考答案

1. 依赖视图：建立仓库之间的接口或依赖关系索引；从用户目标定位可能受影响的仓库及组件。

2. 按需读取：根据依赖选择相关资料而非一次读入所有仓库；核对接口与代码版本避免使用过期关联。

3. 跨会话交接：保存修改范围进展和待验证事项；使下一会话能够沿证据继续核对各仓库的结果。
