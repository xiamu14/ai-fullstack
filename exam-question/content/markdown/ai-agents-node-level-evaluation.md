# 多节点 Prompt 如何归因

## 题干

修改上游 Prompt 后最终结果变差，如何发现是哪个节点发生了退化？

## 参考答案

1. 分项标准：给关键节点定义输入输出及质量标准；同时保留端到端任务标准以防局部最优。

2. 可比记录：保存各节点的输出与调用用量；在相同输入和模型条件下比较修改前后。

3. 退化定位：沿依赖检查错误最初出现及后续传播位置；针对原因修复后同时复测局部与端到端结果。
