# 推荐如何利用用户纠偏

ID: preference-dialogue
Library: ai-agents
Version: 2026-10-24.1

模块：模型交互 · 难度：L2

## 题干

购物推荐里用户不断说“不要这种”“预算不能超”，Agent 应怎样更新推荐依据？

## 参考答案

1. 偏好结构：区分不可违反的硬约束与可权衡的偏好；分别保存喜欢排斥和历史偏好等信息。

2. 会话更新：将用户显式纠偏及时写入当前偏好状态；新的明确要求优先纠正过期推断而非继续照旧推荐。

3. 推荐验证：候选筛选时检查硬约束满足情况；展示有依据的取舍并用交互结果检查是否收敛到真实需求。

这篇论文最值得带走的启发，不是某个具体模块，而是一个很强的研究视角转换：推荐系统长期默认“用户表达能力弱、系统推断能力强”，于是大家不断优化推断器；但这篇论文反过来问，能不能先把用户表达通道做强。
这个视角一旦成立，很多问题就会被重新组织：重点不再只是更准地预测下一点击，而是如何在有限轮交互里快速收敛到用户真实意图；状态不再只是历史行为序列，而要加入会话内持续更新的显式偏好；模型不再只是单一打分器，而需要把硬约束、正向吸引、负向排斥和个性化历史分开处理。
更重要的是，它提醒人：很多工业问题不是“模型不够聪明”，而是“交互带宽不够高”。当系统允许用户用自然语言直接纠偏时，推荐、搜索、导购、内容分发之间的边界都会开始变得模糊。未来真正有潜力的方向，可能不是把推荐做成聊天机器人，而是把高带宽意图表达无缝嵌回原生产品流，让系统在不打断体验的前提下持续被用户校正。

⚡ 项目亮点：从“人找货”到“AI Agent全流程托管”
这套名为 Scout 的 AI 购物 Agent 概念设计，摒弃了传统电商复杂繁琐的分类与广告干预，利用生成式 AI 与自动执行（Agentic Workflow），打造出极具未来感的全自动购物体验：

透明化推理与选品过程（Visible Reasoning）：用户输入需求后，Agent 会在几秒内检索数十款商品并阅读上万条评价，清晰展示“剔除理由”（如重量超标、降噪较弱）与最终推荐的前三名（3 finalists），极大地建立了用户对 AI 选品的信任感。

智能价格预测与自动托管（Buy For Me）：基于历史价格走势图预测降价趋势，用户可设置预算上限（如目标价 $329），开启“Buy for me”授权后，AI 将自动监控并在触发低价时直接完成下单支付。

极简柔和（Soft & Clean）视觉：整体采用低饱和的米白色微阴影卡片，结合高对比的深色 Agent 标识与精致图标，让大量复杂的数据比较与自动任务显得井井有条。

🛠️ UI/UX视角：AI Agent 交互落地细节
1. 结构化“推荐理由”卡片
需求拟合度解析：详情页通过契合项打钩（降噪性能、航续时间、便携度）与超预算项提醒，精准解答“为什么该商品适合你”，辅助快速决策。

2. 无缝的自然语言与快捷指令交互
底部 AI 对话框（Tell Scout...）：常驻底部输入框并配备“为什么选索尼而不选 AirPods？”等快捷 Prompt 标签，降低对话门槛。
